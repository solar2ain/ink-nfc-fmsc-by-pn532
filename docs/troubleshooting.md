# 故障排查

[中文](troubleshooting.md) | [English](troubleshooting.en.md)

## 无法连接串口

先运行 `ports` 核对串口名称，检查 USB 连接，并关闭其他占用串口的程序。Linux 用户还需要串口访问权限。

## 能寻卡但无法完成刷新

固定线圈位置，缩短线圈间距，核对排线方向和屏幕型号。屏幕、金属背板及附近其他天线可能改变耦合效果。避免在刷新期间移动设备。

NFC 供电可能无法满足屏幕刷新负载，尤其是大分辨率屏幕。传图成功与电容电压较高都不能单独证明刷新全程供电足够。压缩只减少传输量，延长预充和分段也不保证降低峰值负载。

`68CA` / `698A` 是驱动板返回的低电压状态。`RF_TIMEOUT` 仅表示未收到有效回包，还可能涉及耦合、通信或读写器响应，不能直接等同于低电压。

## 认证或配置错误

`6985` 表示条件不满足。自动寻卡检测到华为驱动板时，工具会按规则尝试一次已知 PIN；不会猜测或反复重试。核对 `--board`、UID 和自己设置的 PIN。

配置相关错误应核对主控、分辨率、颜色和接线。不要仅修改图片尺寸。不指定 `--screen` 时保留已存驱动，要求实际屏幕与配置一致；无法唯一匹配时请补充主控、分辨率或颜色筛选。指定 `--screen` 会改写配置，不能用于还原原驱动。

## 提示空闲但画面未完成

`DE=00` 是驱动板的状态报告，不是对屏幕图像的校验。应检查实际画面、日志中的忙状态，以及是否发生通信或供电中断。

失败后工具停止，不自动续传或重复刷新。更换耦合位置后应人工重新发起操作，并确认不会覆盖需要保留的配置或图片。

## 提供问题信息

请提供屏幕型号、驱动板类型、读写器型号、实际画面表现及整个日志目录。保留 `run.log`、`summary.json` 和 `details/`；如有本次预览，也一并提供。自定义 PIN 在正常导出日志中脱敏。
