华为驱动板的 `7A/7D` 唤醒、已知 PIN、容量预算及 A0/A1 分段刷新是本工具针对已测试驱动板的适配，不是上述手册对所有 FMSC 芯片的统一规定。9 Hz 轮询和连续三次空闲确认也属于本工具的等待策略。

## 工作流程

本工具执行驱动板中保存的完整屏幕流程，不通过逐条 DC 命令拼接刷新。

1. 使用标准 `26/52` 或特殊 `7A/7D` 的 7-bit 短帧寻卡，选择 UID 后建立 ISO-DEP 会话。
2. D1 读取驱动板信息，核对 UID、APPID、屏幕尺寸、扫描方式和压缩能力。APPID 不等于唯一硬件型号。
3. D8 检查访问权限。特殊唤醒华为板返回 `6985` 时仅验证一次已知 PIN，再检查 D8；标准唤醒模式不发送 PIN。
4. 需要更新驱动时写 DB 和 DA，再用 D1 核对配置。
5. 通过 D3 压缩传图，或显式通过 D2 传原始数据。
6. D4 执行已存屏幕流程，包含配方规定的复位、初始化、RAM 写入、PON、DRF、BUSY 握手和 POF。
7. DE 查询忙状态，默认目标频率 9 Hz。已观察到忙状态后，连续三次空闲即结束等待；若始终未观察到忙状态，完整刷新仍等待配方最低观察时间并提示无法确认。分段刷新必须观察到忙状态后才进入下一段。

## 主要命令

下表章节号对应上述完整版开发手册。

| 命令 | 作用 | 手册章节 |
|---|---|---|
| `00 D1 00 00 00` | 读取驱动板 TLV 信息 | 7.4 |
| `F0 D8 00 00 05 00 00 00 00 0E` | 读取用户区前缀并检查访问权限，不是读取屏幕配置 | 7.14 |
| `F0 DB 02 00 00` | 清除已存驱动；后续 DB 包写入完整驱动 | 7.10 |
| DA | 设置屏幕类型、扫描方式 | 7.9 |
| D2 / D3 | 原始 / 压缩图像写入 | 7.5 / 7.6 |
| `F0 D4 85 80 00` | 异步执行已存驱动并刷新 | 7.7 |
| `F0 DE 00 00 01` | `01` 为忙，`00` 为空闲 | 7.12 |

用户区、屏幕驱动和图槽是不同区域。认证成功或图像写入成功，不等于已经启动高压或完成刷新。

## 读写器兼容

默认模式将 ISO-DEP INF 限制在 240 bytes，以兼容 PN532/PCR532 的普通 UART 帧。FMSC 图像子包的 250-byte 固定步长不改变，ISO-DEP 链接层负责分帧。

`--reader pn532` 在协商允许时可使用最多 253-byte INF；`--reader pcr532` 与默认安全策略一致。自动兼容不代表能够识别读写器商品型号，也不调整发射功率。

无回包会停止当前交换和整个操作，不自动重发写入、D4、PIN 或重新寻卡。等待刷新期间不主动关场；操作结束或取消时尝试关闭射频场。读写器完全无响应时可能无法执行关场，应移开标签。

## 存储与屏幕限制

D2 每图槽最多 256 包，每包固定步长 250 bytes。D3 将原始图像按 2000-byte 块独立压缩，压缩子包步长仍为 250 bytes。包数受压缩效果影响，不能直接用 APDU 数量推断存储容量。

A0/A1 分段刷新保留物理尺寸 768×552，仅改变 RAM 和刷新 source 窗口。每段都执行配置、传图和刷新，不能简单按连续字节流切成两半。完成后图槽与驱动仅保存末段；另一段是否保持原画面需要实测。

其他主控没有通用分段方案。刷新窗口也不保证窗口外电极完全不参与扫描。

六色圆屏、高分辨率屏和部分配方仍存在供电或适配限制。软件校验会检查尺寸、数据布局、极性、驱动指纹和危险命令，但不能代替未知屏幕的接线和规格核对。
